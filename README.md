# ByteLark Website Templates

A growing collection of website templates built for learning, inspiration, and practical use.

This repository is the source referenced in the ByteLark YouTube channel, where I share template builds, UI ideas, and implementation walkthroughs.

## Current Coverage

Right now, the repo includes these template categories:

- `Bar`
- `Cafe`
- `Restaurant`

Each category is intended to contain one or more website templates and related assets.

## Roadmap

The plan is to continuously expand this repository with more templates, especially:

- Modern website templates
- Creative and visually polished designs
- Better structure and reusable patterns across templates

More categories and improved versions will be added over time as new videos and projects are published on ByteLark.

## Why This Repo

- Central place for all website template code from the channel
- Easy to clone, explore, and reuse
- Built to grow into a broader template library
